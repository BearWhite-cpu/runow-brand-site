# RUNOW brand site

A responsive, single-page concept website for RUNOW. Built with plain HTML, CSS and JavaScript; no build step is required.

## Publish with GitHub Pages
A GitHub Actions workflow is included at `.github/workflows/pages.yml`. After the first push, open **Settings → Pages** and ensure the source is **GitHub Actions**. The workflow should deploy the site automatically.

## Before public launch
- Replace the example contact address `hello@runow.run` in `index.html` with a real address you control.
- Review the brand wording and replace concept copy as needed.
- The orbital illustration is an inline SVG concept, not a final approved logo.
- Fonts load from Google Fonts; if that service is unavailable, the site falls back to system fonts.
